# Changelog

All notable changes to `live-lexxy` will be documented in this file.

## [0.1.0] - 2026-01-16

### Added
- Initial release
- Livewire component for rich text editing
- Built on Lexical editor framework (v0.38.2)
- Markdown support with shortcuts
- Code syntax highlighting
- Table support
- Customizable toolbar
- Two-way data binding with Livewire
- Configuration file for defaults
- Example implementations
- Comprehensive documentation
- Quick start guide

### Features
- Bold, italic, strikethrough text formatting
- Headings (H1, H2, H3)
- Lists (ordered and unordered)
- Block quotes
- Code blocks
- Links
- Tables
- Clean HTML output with semantic tags
- Alpine.js integration
- TALL stack compatible

### Security
- Updated DOMPurify to v3.1.3 (fixes XSS vulnerabilities)
- Content sanitization by default
- Secure HTML generation

### Documentation
- README.md with comprehensive overview
- INSTALLATION.md with step-by-step setup
- QUICKSTART.md for quick setup
- docs/API.md with complete API reference
- docs/USAGE.md with practical examples
- docs/CONFIGURATION.md with customization options
- CONTRIBUTING.md with contribution guidelines
- Examples for simple and advanced usage

### Developer Experience
- Build script for asset compilation
- Published assets system
- Publishable views for customization
- Clear separation of concerns
- Well-commented code
